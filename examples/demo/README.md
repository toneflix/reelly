# Lumen

Lumen is a calm notes app that links your ideas as you type.

- **Pages**: write in a distraction-free editor. As you type, Lumen surfaces linked ideas from the rest of your workspace.
- **Board**: drag tasks between To do, In progress and Done.
- **Insights**: see how much you wrote and linked this month.
- **Share**: invite people by email and turn on a public link.

Tagline: *Notes that think with you.* Website: lumen.app

(This is the demo product that ships with the reelly plugin. It is a static page with no backend.)
